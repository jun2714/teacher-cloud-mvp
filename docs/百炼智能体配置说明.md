# 阿里云百炼 · 教研云智能体配置说明

给控制台「创建智能体应用」用。配好后把 **应用 ID**、**API Key** 发我，后端即可改为远程调用。

当前教研云有 **4 个 AI 任务**，建议做成 **1 个应用**，按 `任务类型` 分流，不要做成 4 个应用。

---

## 一、创建应用时怎么选

| 项 | 建议填写 |
|----|----------|
| 开发方式 | 低代码 |
| 类型 | **Agent 1.0 更稳**（生成长文教案/报告）。你已选 Agent 2.0 也可以，但先**不要加工具/插件**，否则容易变成「调工具」而不是直接出文稿。 |
| 应用名称 | `教研云教研助手` |
| 描述信息 | `服务教师：教学设计、听评课分析、教研报告、疑惑交流参考回答。输出可执行、对齐新课标，不评价教师能力。` |
| 应用头像 | 可用默认机器人 |

Agent 2.0 若一定要用：把「工具调用 / MCP / 插件」先全部关掉，只保留指令。知识库以后有课标、校本材料再挂。

- 只输出可落地的教研文稿或参考回答，不要闲聊。

## 三、功能方面：现在先不要配这些

教研云后端会自己调这个应用，应用只要**直接生成正文**。

请先不要配置：
- MCP / 插件 / 自定义工具（Function Call）
- 让智能体去调我们服务器的接口
- 联网搜索（除非你明确要）

以后可以加（加之前告诉我，调用方式可能要改）：
- 知识库：新课标原文、校本作业样例、教研制度
- 记忆：同一老师连续备课（需要会话 session_id）

---

## 四、模型建议

在应用里选一个适合长文生成的模型即可，例如：
- `qwen-plus` 或 `qwen-max`（教案、报告更稳）
- 答疑也可以同一模型，不必拆开

生成长度：尽量允许较长输出（教学设计经常超过 1500 字）。

## 六、语音转写（听评课 / 笔记音频）

听评课和笔记上传的音视频走百炼 **Paraformer 录音文件识别**，复用同一把 `AI_API_KEY`，不必再开智能语音交互 AppKey。

1. 控制台开通「语音识别 / 录音文件识别」（模型 `paraformer-v2`）。
2. 后端 `.env` 保持 `AI_API_KEY`；可选 `ASR_MODEL=paraformer-v2`。
3. 接口：`POST /api/asr/transcribe/`，前端选文件后自动填入转写文本。
